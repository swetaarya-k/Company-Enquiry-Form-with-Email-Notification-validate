# Company-Enquiry-Form-with-Email-Notification-validate
📌 Project Overview

The Company Enquiry Form with Email Notification & Validation is a full-stack web application designed to collect customer enquiries in a structured and secure manner.

This system allows users to submit their queries through a responsive form interface. The application performs real-time validation to ensure accurate data entry and automatically sends an email notification upon successful submission.

The project demonstrates strong concepts of frontend form handling, backend integration, validation techniques, and automated email services.

🎯 Objectives

To design a professional company enquiry interface

To implement client-side and server-side validation

To integrate automatic email notification functionality

To ensure secure and structured data handling

To build a responsive and user-friendly UI
